# 傻瓜画图 · Shagua Chart

**粘贴数据，选个样子，导出图。** 一个单文件 HTML 的零门槛图表工具，支持折线图、柱状图、饼状图、散点图——双击打开就能用，不装软件、不联网、数据不离开本机。

**在线试用**：<https://shagua-chart.app.workbuddy.host/?sharecode=L4RPLV5TDS> （国内直连，不想下载就直接打开；数据同样只留在你自己的浏览器里）

备用入口（GitHub Pages）：<https://dddg637.github.io/shagua-chart/>

![界面总览](https://cdn.jsdelivr.net/gh/DDDG637/shagua-chart@main/docs/screenshot.png)

## 为什么做这个

日常画图的选择其实都不太顺：

- **Excel / WPS**：出图样式难精调，导出矢量和字体控制别扭；
- **ECharts / Chart.js**：得写配置或代码，对不写前端的人是门槛；
- **在线图表网站**：要联网、要上传数据、导出常带水印或限分辨率。

这个工具把流程压到最短：**粘数据 → 点两下 → 导出**。整个程序是一个 `index.html`，约 60 KB，没有任何外部依赖，发给别人也能直接打开。

## 功能

**数据录入**
- 左右分栏输入横轴与纵轴，或直接把 Excel 里的整块表格粘进来——自动按 Tab / 逗号 / 分号 / 多空格拆分，多列即多系列，首行文字自动识别为图例名。
- 脏数据自动清洗：全角数字（`８２％`）、千分位（`1,234.5`）、货币与百分号（`¥1.2万`、`82%`）、`万`/`亿` 单位换算、空行跳过、非法值跳过并提示。长度不等时按短侧对齐，不打断操作。

**图表**
- 四种图型：折线、柱状（分组并排 / 堆叠）、散点、饼图。
- 多系列对比：图例自动换行居中，折线遇空值自动断线（不会连出穿越缺口的假线）。
- 横轴类型可选 自动 / 分类 / 数值。数值轴下按真实 X 值定位并排序连线，适合标曲、相关性这类场景。
- 排版自适应：Y 轴刻度用 nice number 取整；X 标签过密自动 -35° 旋转、再密则按间隔抽样；有负值时画零基线并扩展坐标范围。
- 负值默认显示为绿色（符合国内涨跌习惯，可关闭）。

**点击改色**（下图）

![点击改色](https://cdn.jsdelivr.net/gh/DDDG637/shagua-chart@main/docs/color-picker.png)

直接点折线、柱子、散点、饼图扇区、图例或左侧色点，弹出取色面板：15 个预设色 + 系统取色器 + 恢复默认。悬停某条线时其余系列会淡出，避免多系列下点错。

**导出**
- PNG，2 / 3 / 4 倍分辨率（800×500 画布 → 默认 2400×1500），印刷够用；
- SVG 矢量，可直接进 Illustrator / Inkscape；
- 一键复制到剪贴板。
- 导出前会剥离所有交互标记与透明命中层，产物干净，不留隐形元素。

**其他**
- 数据自动存本机 `localStorage`，关掉再打开还在；
- 支持图表标题、轴标题、脚注（数据来源），脚注按画布宽度自动换行。

## 开始使用

**方式一：在线用。** 打开 <https://shagua-chart.app.workbuddy.host/?sharecode=L4RPLV5TDS> ，无需下载。

**方式二：本地用（推荐，永久离线可用）。**

1. 下载本仓库的 [`index.html`](index.html)；
2. 双击用浏览器打开（Chrome / Edge / Firefox 均可）；
3. 点「载入示例」看效果，或直接粘自己的数据。

不需要构建、不需要 `npm install`、不需要起服务器。

## 数据格式

在「横轴数据」和任意系列框里各贴一列即可，或者一次贴一张表：

```
季度      甲公司   乙公司
第1季度    12.4    9.8
第2季度    15.8    11.2
第3季度    14.2    13.6
第4季度    21.6    15.1
```

上面这段粘进任意一个输入框，会自动变成：横轴 4 项 + 两个系列，图例名取首行。

## 技术说明

- **手写 SVG，不引图表库**。折线、柱状、散点、饼图共约 400 行渲染代码，换来的是：文件小、矢量导出零成本、字体与刻度完全可控、没有版本升级带来的破坏性变更。
- **单文件、零依赖、ES5 语法**，保证老浏览器和本地 `file://` 直接打开都能跑。
- **渲染即快照**：`draw()` 拼出完整 SVG 字符串后写入容器，导出直接复用该字符串，所见即所得；交互靠 `data-series` / `data-pie` 标记 + 事件委托回溯，不用给每个元素单独挂监听。
- **状态单一**：一个 `state` 对象 + `localStorage`，改动即存、即重绘。

### 兼容性

现代版 Chrome / Edge / Firefox / Safari。依赖 SVG、`localStorage`、`Canvas.toBlob()`（导出 PNG 用）与 `ClipboardItem`（复制用，不支持时降级提示改用导出）。

## 已知限制

- 饼图只使用第一个系列；
- 没有悬浮 tooltip 与入场动画（预览场景以静态出图为主，刻意省略）；
- 不支持双 Y 轴、对数轴、误差线；
- 数据点很多（> 100）时数据标签会拥挤，建议关闭标签。
